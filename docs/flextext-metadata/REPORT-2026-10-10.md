### A1 The helper: **done (Linux-verified with fakes), real FLEx path unverified**

- `src/flextext/main/helper/HelperClient.ts`: one long-lived process, spawned from main only
  (`shell:false`, `windowsHide:true`, not detached), stderr drained into a ring buffer and the log,
  per-call timeouts (a timed-out call sends `cancel`), cancel by message, restart with backoff
  (1 s … 30 s, optional give-up), `shutdown` → 3 s → `kill()`. `pidFile.ts`: PID file plus a
  stale-helper sweep that kills only on Windows and only when `tasklist` says the PID's image is
  `flextext-helper.exe`. Exposed with `ipcMain.handle` (`FlexText.helper.*`) and consumed from the
  renderer by `src/flextext/helper/HelperApiAccess.ts` (`ipcRenderer.invoke` wrappers, mockable),
  the pattern of `MainProcessApi.ts` / `MainProcessApiAccess.ts`. lameta runs with
  `contextIsolation:false`, so there is no `contextBridge` to use; the task's "preload/contextBridge"
  is met in the only form the host allows.
- `helper/flextext_helper` (Python): newline-delimited JSON-RPC 2.0 on stdio; the main thread
  reads stdin and answers `ping`/`cancel`/`shutdown` at once; a **single "flex" lane thread owns
  every LCM call**; a "general" lane serves rclone so a long FLEx scan never blocks backup
  progress. Cancel drops a queued request (error `-32001`) or sets the running one's flag, which
  long handlers poll. Exit on stdin EOF; parent-PID watchdog (psutil) with a hard exit behind it.
  Windows Job Object with `KILL_ON_JOB_CLOSE` through ctypes, a guarded no-op elsewhere.
  Based on fdat's `desktop/sidecar/fdat_lcm.py` (fetched; its `serve` loop and session shape
  reused, moved from flexlibs to flexicon). `FlexAdapter` interface with `FakeFlexicon` (synthetic
  data) and `RealFlexicon` (`import flexicon` lazily, never `flexlibs2`; checks the major version
  is 4). Methods: `ping, listProjects, openProject, closeProject, currentProject, listTexts,
  readText, textStats, readGenres, readPeople, sharingStatus, flexInfo`. Errors:
  `FP_FileLockedError` → `-32010` with the Sharing-tab message; `FP_MigrationRequired` →
  `-32011` "open the project in FLEx once first".
- `helper/flextext-helper.spec`: PyInstaller `--onedir`, flexicon collected as plain `.py` files
  (excluded from the PYZ), pythonnet/clr_loader as hidden imports.
- `helper/THIRD-PARTY-NOTICES/`: flexicon LGPL-2.1 (copied from the wheel), pythonnet MIT (added
  by hand; the wheel ships none), clr_loader MIT (the wheel does ship it), rclone MIT, README.
- pytest: **41 tests pass** (server loop, cancel, lanes, EOF, watchdog as a subprocess, methods and
  error mapping, textStats, backup request building, methods against a fake rc server, platform
  guards, and an end-to-end backup/restore/history against a real `rclone serve s3` on loopback).

### A2 S3 backup: **done (fake and loopback-verified), real S3 unverified**

- Helper: `rclone rcd` on `127.0.0.1:<random port>` with a random user/password per start;
  credentials only in `RCLONE_CONFIG_FTS3_*` environment variables (`RCLONE_CONFIG` points at a
  file that is never written); backup = async `sync/sync` of the project folder with
  `_config.BackupDir = <bucket>/<prefix>-history/<project>/<timestamp>`; excludes `Thumbs.db`,
  `desktop.ini`, `.DS_Store`, `.flextext-open.json`; `job/stop`, `core/stats`, `core/bwlimit`;

  (PLAN §8). Passes on Linux with rclone v1.68.2.
- App: Backup tab (seam `workspace-tabs`, which registers every fork tab in one place) in lameta's

  restore via a folder picker.

### A3 Device cooperation: **done (contract unchanged)**

- `<project>/.flextext-open.json` `{app, version, pid, since, heartbeat}`, written on open,
  heartbeat every 30 s (atomic temp-file rename), deleted on close unless another instance has
  since written it; staleness helper at 2 minutes; excluded from backups. Timestamps are ISO 8601
  UTC to the second, exactly like the contract's example.
- A `Sessions/` watcher (`fs.watch` on the folder and on each session folder, plus a 5 s rescan as
  the safety net) loads a new session folder the moment it holds a `.session` file, and reloads a
  changed `.session` unless it is the selected (being edited) session, in which case the change
  waits until the selection moves. A change that merely re-saved what is in memory is ignored.
- Seam `project-open` in `ProjectHolder.setProject`. Off under vitest unless a test opts in, so
  upstream's tests never write a marker into `sample data`. Tested end to end on a temp copy of
  the Edolo sample.

## Open questions

- **Contract (§5), no change made, two notes for the suite side:** (1) the marker's timestamps are
  written to the second (`2026-10-09T20:00:00Z`), as in the example; if the agent compares with
  millisecond precision nothing breaks, but it should parse rather than string-compare. (2) `pid`
  is the Electron main-process pid; an agent on the same machine could additionally treat a marker
  whose pid is dead as stale, which would shorten the 2-minute window after a crash.
- **Status rule timing:** the mirror applies the Status rule only when the fork's own code saves
  a session's progress (`applyStatus: true`), never on load, per the spec. A "Recompute Status for
  all sessions" action is not built.
- **Window title:** currently "<project> <lameta version> – FlexText Metadata (for lameta)".
  Should the fork's own version appear instead of lameta's?
- **Icon:** the installer still uses lameta's `build/windows.ico`. A fork icon avoids two identical
  icons in the Start menu.
- **Automatic backups** run from the Backup tab's timer only while that tab is mounted (the tab is
  part of the workspace, so while a project is open). Is a main-process scheduler wanted?
- **Checklist UI scope:** which first screen, the per-session steps or the target overview?
- **rclone pin:** v1.68.2 (the SHA256SUMS of that release were reachable; newer versions exist).
- **Lingui:** the fork's UI strings use `Trans` like upstream but are not extracted into the
  catalogs (`yarn strings:extract` is upstream's command and would modify `locale/`); they display
  in English.
